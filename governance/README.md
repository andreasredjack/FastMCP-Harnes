# Governance-Testkonfiguration

Diese Dateien gelten ausschließlich für die isolierte Governance-Testkopie.
Sie sind ein technischer Prototyp für ISO/IEC 42001-, EU-AI-Act- und DSGVO-
Kontrollen. `TBD`, `pending` und `assessment_required` sind absichtliche
Fail-Closed-Signale und müssen vor einer Betriebsfreigabe ersetzt werden.

Die Konfiguration ist keine Rechtsberatung und keine Konformitätserklärung.
